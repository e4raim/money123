# Конвейер сайтов

Генератор одностраничных сайтов для холодных продаж локальному бизнесу.
Один HTML-шаблон + JSON-конфиг на клиента → готовый самостоятельный HTML-файл,
который можно открыть в браузере, отправить по ссылке или залить на любой хостинг.

Это отдельный проект, не связанный с остальными файлами в корне репозитория
(`index.html`, `Ddd.html` и т.д. — другой продукт, не трогаем).

## Как это работает

```
site-factory/
  template/index.html       мастер-шаблон (Jinja2), дизайн + вся вёрстка
  configs/<клиент>.json     данные конкретного бизнеса
  output/<клиент>.html      готовый файл — то, что показываем клиенту
  generate.py                генератор
```

1. Копируешь `configs/barbershop-example.json` в `configs/<имя-клиента>.json`.
2. Меняешь название, телефон, адрес, часы работы, услуги/цены, состав мастеров,
   отзывы — под конкретный реальный бизнес, который нашёл.
3. Генерируешь:
   ```bash
   pip install jinja2   # один раз
   python3 generate.py configs/<имя-клиента>.json
   ```
4. Открываешь `output/<имя-клиента>.html` в браузере — это и есть демо-сайт.
   Его можно отправить клиенту ссылкой (через Artifact/файлом) до звонка
   или показать прямо во время разговора.

## Процесс продаж (конвейер)

1. Находишь реальный локальный бизнес без сайта (или с плохим сайтом) —
   Google/Яндекс Карты, 2ГИС.
2. За 10–15 минут собираешь конфиг с их реальным названием, адресом, услугами
   и ценами (можно взять с их страницы в соцсетях/картах).
3. Генерируешь готовый сайт, смотришь глазами — не забыл ли подставить всё.
4. Звонишь/пишешь: «Я сделал вам сайт, посмотрите» + ссылка.
5. Если человек хочет купить — переносишь на постоянный хостинг
   (Vercel/Netlify/обычный хостинг — это статический HTML, работает где угодно)
   и получаешь оплату.

## Дизайн-направление и что было исправлено

Линейка сайтов держится на скилле `design-taste-frontend` (анти-шаблонный чек-лист
для лендингов). Он написан под React/Tailwind/Motion-стек — этот стек тут
намеренно не используется: конвейер держится на голом HTML без сборки,
чтобы один файл можно было открыть где угодно за секунду. Применены
стек-независимые правила (палитра, типографика, структура секций, живые
CTA), стек-специфичные (GSAP-паттерны, Tailwind-классы) — нет.

При аудите первой версии барбершоп-демо нашлось и исправлено:
- **Палитра была в списке запрещённых** — бронза на угле совпадала с
  «AI-дефолтом» для премиальных потребительских брендов. Заменил на
  холодную сталь/кобальт — по смыслу барбершопу (бритвы, хром, зеркала)
  подходит даже лучше.
- **6 «eyebrow»-подписей над каждой секцией** («О нас», «Прайс», «Команда»…) —
  классический AI-паттерн, лимит — не больше 2 на 6 секций. Убрал все,
  заголовки работают сами.
- **Trust-строка под кнопками в hero** (адрес/телефон/кол-во мастеров) —
  запрещённый паттерн, эта информация и так есть в шапке и в футере. Убрал.
- **Разные подписи у одной и той же кнопки** («Позвонить» / «Позвонить
  сейчас», «Написать в WhatsApp» / «Записаться в WhatsApp») — свёл к одной
  подписи на каждое действие.
- Добавил опциональную секцию `gallery` в шаблон (рендерится, только если
  в конфиге есть фото) — на реальном клиенте это должны быть его настоящие
  фото, не стоковые заглушки.

**Сознательное отступление от чек-листа:** правило skill'а «ноль тире (—/–)
где угодно на странице» — это защита от англоязычного AI-тика. В русском
языке тире — обычный грамматический знак (конструкции вида «X — это Y»,
диапазоны «10:00–20:00»), а не AI-маркер. Механически вычищать его из
текста конфигов значило бы делать копирайт менее естественным, а не более.
Тире убраны только там, где они были чисто декоративным ходом (заголовок
`<title>`); в теле текста — оставлены.

## Фото для реальных клиентов

- Шаблон по умолчанию — типографический, без фото (так безопаснее для
  предпросмотра через Artifact-ссылку: внешние картинки там не грузятся
  из-за CSP, работают только шрифты Google Fonts).
- Когда есть реальный бизнес — добавляешь в конфиг `"gallery": [{"src": "...",
  "alt": "..."}, ...]`. Фото берёшь с их карточки в Я.Картах/2ГИС/Instagram
  или присылаешь мне файлом в чат.
- На **финальном хостинге** (не в Artifact-превью) внешние ссылки на фото
  работают без ограничений — это обычный HTML-файл.

## Что можно докрутить дальше

- Свои варианты шаблона под другие ниши (кафе, автосервис, стоматология,
  салон красоты) — копируешь `template/index.html`, меняешь палитру/тексты
  под нишу, кладёшь как `template-cafe/`, `template-auto/` и т.д.
- Параметризовать палитру через конфиг (сейчас цвета зашиты в CSS
  под барбершоп — бронза/уголь). Для новых ниш проще пока просто
  скопировать и перекрасить шаблон вручную.
- Форма заявки с реальной отправкой (сейчас CTA — это просто `tel:`
  и WhatsApp-ссылка, что осознанно: не требует бэкенда и работает сразу).
