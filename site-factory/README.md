# Конвейер сайтов

Генератор одностраничных сайтов для холодных продаж локальному бизнесу.
Один HTML-шаблон + JSON-конфиг на клиента → готовый самостоятельный HTML-файл,
который можно открыть в браузере, отправить по ссылке или залить на любой хостинг.

Это отдельный проект, не связанный с остальными файлами в корне репозитория
(`index.html`, `Ddd.html` и т.д. — другой продукт, не трогаем).

## Как это работает

```
site-factory/
  template/index.html       мастер-шаблон (Jinja2), дизайн + вся вёрстка
  configs/<клиент>.json     данные конкретного бизнеса
  output/<клиент>.html      готовый файл — то, что показываем клиенту
  generate.py                генератор
```

1. Копируешь `configs/barbershop-example.json` в `configs/<имя-клиента>.json`.
2. Меняешь название, телефон, адрес, часы работы, услуги/цены, состав мастеров,
   отзывы — под конкретный реальный бизнес, который нашёл.
3. Генерируешь:
   ```bash
   pip install jinja2   # один раз
   python3 generate.py configs/<имя-клиента>.json
   ```
4. Открываешь `output/<имя-клиента>.html` в браузере — это и есть демо-сайт.
   Его можно отправить клиенту ссылкой (через Artifact/файлом) до звонка
   или показать прямо во время разговора.

## Процесс продаж (конвейер)

1. Находишь реальный локальный бизнес без сайта (или с плохим сайтом) —
   Google/Яндекс Карты, 2ГИС.
2. За 10–15 минут собираешь конфиг с их реальным названием, адресом, услугами
   и ценами (можно взять с их страницы в соцсетях/картах).
3. Генерируешь готовый сайт, смотришь глазами — не забыл ли подставить всё.
4. Звонишь/пишешь: «Я сделал вам сайт, посмотрите» + ссылка.
5. Если человек хочет купить — переносишь на постоянный хостинг
   (Vercel/Netlify/обычный хостинг — это статический HTML, работает где угодно)
   и получаешь оплату.

## Что можно докрутить дальше

- Свои варианты шаблона под другие ниши (кафе, автосервис, стоматология,
  салон красоты) — копируешь `template/index.html`, меняешь палитру/тексты
  под нишу, кладёшь как `template-cafe/`, `template-auto/` и т.д.
- Параметризовать палитру через конфиг (сейчас цвета зашиты в CSS
  под барбершоп — бронза/уголь). Для новых ниш проще пока просто
  скопировать и перекрасить шаблон вручную.
- Форма заявки с реальной отправкой (сейчас CTA — это просто `tel:`
  и WhatsApp-ссылка, что осознанно: не требует бэкенда и работает сразу).
