# Чек-лист доступности перед сдачей UI-правки

В проекте уже есть база (аудит контраста/touch-таргетов/имён и переход на
единый набор stroked-иконок — см. `git log`). Этот чек-лист — чтобы не
откатиться назад при новых правках `index.html`.

## Перед коммитом любой UI-правки

- [ ] **Цвет — не единственный носитель смысла.** Статусы `works`/
      `thinking`/`refusal`/`base` (`.chip .dot`, `.pill`) передаются точкой/
      цветом — рядом всегда должен быть текст или иконка, а не только цвет.
- [ ] **Контраст.** Для текста использовать `-t` переменные
      (`--ok-t`, `--think-t`, `--no-t`, `--base-t`), для заливки под белым
      текстом — `-s` (`--ok-s` и т.д.). Не брать «сырые» `--ok`/`--think`/
      `--no`/`--base` под текст — они подобраны под контраст 4.5:1 только в
      паре со своим назначением. Новый цвет статуса — сразу считать обе
      версии, не только на глаз.
- [ ] **Иконки без подписи.** Любая кнопка/иконка без видимого текста —
      обязательно с `aria-label` (в проекте уже так почти везде, не
      регрессировать). Декоративные `<svg>` внутри подписанных кнопок —
      `aria-hidden="true"`.
- [ ] **Touch-таргеты.** Интерактивные элементы ≥ 24×24px фактической
      области клика (с учётом padding), в идеале ближе к 44×44 на мобильной
      раскладке (`.grid.list`, нижняя панель).
- [ ] **Минимальный размер текста.** Не опускаться ниже 11px ни для какого
      читаемого текста (см. коммит про эмодзи/иконки — это уже было
      правилом).
- [ ] **Клавиатура.** Новые интерактивные элементы должны быть достижимы
      Tab'ом и иметь видимый `:focus`. Формы (`#authEmail`, `#authPass` —
      пример) — Enter должен либо переводить фокус дальше, либо сабмитить,
      как уже сделано в `authGate`.
- [ ] **Тёмная тема.** Проверить правку и в `body.dark`, и в
      `prefers-color-scheme: dark` без класса — оба пути определены
      отдельно в CSS, легко забыть один.
- [ ] **Приватный режим.** Если правка касается ФИО/контактов владельца —
      проверить, что `body.privacy` по-прежнему их скрывает.

## Быстрая проверка глазами

1. Открыть DevTools → Rendering → Emulate `prefers-contrast: more` и
   пройтись по изменённому экрану.
2. Уменьшить окно до ~360px шириной — проверить touch-таргеты и что текст
   не срезается.
3. Пройти изменённый экран одной клавиатурой (без мыши).
