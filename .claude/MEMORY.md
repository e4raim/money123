# Память проекта (заметки между сессиями)

Сюда дописываются короткие записи о решениях, договорённостях и граблях —
чтобы не объяснять их заново в каждой новой сессии Claude Code. Не история
коммитов (для этого есть `git log`), а именно контекст и причины.

Формат новой записи:

```

Что решили / что узнали. Почему. Что осталось сделать (если есть).
```
